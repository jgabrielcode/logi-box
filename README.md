# 📦 Logi Box

O **Logi Box** é um projeto voltado para o desenvolvimento de uma ferramenta digital para auxiliar profissionais da área de logística em tarefas e cálculos presentes no dia a dia operacional.

## 💡 Sobre o projeto

A ideia inicial do Logi Box surgiu a partir de uma necessidade específica: desenvolver uma ferramenta capaz de realizar a **conversão de milheiros para unidades e de unidades para caixas**.

Com o desenvolvimento do projeto, a ideia foi evoluindo. O objetivo deixou de ser apenas criar um conversor e passou a ser desenvolver, gradualmente, um **sistema com diferentes ferramentas e funcionalidades voltadas para a rotina logística**.

A proposta é reunir, em um único lugar, recursos que possam facilitar tarefas, cálculos e consultas que fazem parte do cotidiano de operações logísticas.

## 🚀 Funcionalidades atuais

Atualmente, o Logi Box possui duas funcionalidades principais:

* 🔢 **Milheiro → Unidades**
* 📦 **Unidades → Caixas**

Essas funcionalidades representam a primeira etapa do projeto e servem como base para a expansão da aplicação.

## 🔮 Visão do projeto

A ideia é evoluir o Logi Box para uma ferramenta logística mais completa, adicionando funcionalidades que tenham **aplicação prática no dia a dia**, sempre buscando identificar problemas ou tarefas que possam ser simplificados por meio da tecnologia.

O projeto está sendo desenvolvido de forma gradual, permitindo que novas funcionalidades sejam adicionadas conforme novas necessidades forem identificadas.

## 🏢 Aplicação prática

Além de ser um projeto de estudo e desenvolvimento, o Logi Box também foi apresentado aos gestores da empresa onde trabalho.

A apresentação recebeu **feedback positivo e elogios**, o que reforçou a ideia de continuar desenvolvendo o projeto e buscar novas possibilidades de aplicação dentro do contexto logístico.

## 📌 Status

🚧 **Em desenvolvimento**

O projeto está em sua fase inicial, atualmente contando com duas funcionalidades de conversão e com planos de expansão para novas ferramentas voltadas à logística.
